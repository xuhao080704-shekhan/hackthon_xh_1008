同频 · Windows 比赛现场演示

1. 直接双击同文件夹中的“启动演示.cmd”。
2. 浏览器会自动打开；不用安装软件，不用输入访问码。
3. 点击“载入共同时间样例”，再打开“共同时间”。
   周一应显示 10:00—10:30，周三应显示 15:00—16:00。
4. 点击“载入无交集样例”，演示系统如何处理没有共同时间。
5. 切回“我的可行时间”，选择模拟成员 A/B/C，修改并保存，可演示真实提交与覆盖更新。
6. 点击“清除本周样例”，回到提交不足的状态。
7. 结束时在启动窗口按 Ctrl+C。数据保存在 .demo 文件夹，重启仍保留。

演示数据明确标注为模拟数据，但提交、SQLite 存储和聚合均为真实实现。
本包无需网络的功能：手动提交、模拟成员切换、样例载入、共同时间计算、结果页面。
“本周目标档案”使用真实外部 AI，需要联网与有效密钥。双击“配置AI.cmd”，按中文窗口填写 API 地址、模型、密钥，保存后重启；无需改代码。没有密钥时会明确提示，不会展示伪造解析结果。
建议赛前联网生成并保存一份实际档案。历史档案的读取、编辑、保存、JSON/Markdown 导出可在断网时展示。

复制到另一台 Windows 64 位电脑时，请复制整个 Tongpin-Windows 文件夹并先解压到本地。
不要只复制启动文件。不要在压缩包内直接双击。建议提前在比赛电脑试运行一次。
默认只在当前电脑打开，不需要防火墙、局域网、云服务器或数据库配置。
端口被占用时程序自动尝试下一个端口。
数据和启动日志保存在 .demo，关闭程序后可备份此文件夹。
